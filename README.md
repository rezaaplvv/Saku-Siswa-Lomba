# SakuSiswa - Digital Tabungan & Literasi Keuangan Siswa Sekolah

SakuSiswa adalah platform manajemen tabungan siswa berbasis web modern yang dirancang untuk sekolah dasar, memudahkan pengelolaan tabungan siswa, transparansi untuk orang tua, serta rekapitulasi data keuangan untuk guru dan sekolah.

## 🚀 Fitur Utama
- **Multi-Role Portal**: Akses khusus untuk Admin Sekolah, Guru Kelas, dan Wali Murid.
- **Kartu Identitas & Slip Login**: Cetak slip login dan kartu akun siswa instan.
- **Pencatatan Setor & Tarik**: Transaksi cepat dengan konfirmasi guru & notifikasi orang tua.
- **Ekspor Laporan**: Unduh rekapitulasi keuangan dalam format PDF & CSV.
- **Desain Responsif**: Pengalaman seluler (Mobile Bottom Navigation Bar) dan Desktop (Sidebar Layout) yang disesuaikan secara dinamis.

## 🛠️ Teknologi
- **Framework**: Laravel 11 / 12 with Livewire
- **Styling**: Tailwind CSS
- **Database**: MySQL
